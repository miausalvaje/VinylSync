# vinyl-lyrics

Aplicación local para Windows que identifica la canción reproducida desde un
tocadiscos y muestra su letra sincronizada a pantalla completa.

## Estado del proyecto

El proyecto se está construyendo por fases. Esta primera fase contiene el
esqueleto del repositorio, la configuración base y los metadatos del proyecto.

## Requisitos previstos

- Python 3.11 o superior
- Un dispositivo de captura compatible con `sounddevice`
- Credenciales opcionales para los proveedores de reconocimiento alternativos

## Desarrollo

La instalación y los comandos de ejecución se documentarán junto con la
implementación del backend y la interfaz web.
